# GamePort site

The public site of [GamePort](https://github.com/gameport-project/gameport-app): every Steam game that has an Android version, and what players report for each kind of device. In English and French.

It reads the catalog of [gameport-catalog](https://github.com/gameport-project/gameport-catalog) and the totals of the players' answers from the GamePort relay, and is published on GitHub Pages. Only totals are shown: the technical reports players can send are never published.
